## ✨ 한 줄 정의

**Three.js + Vite로 만든 · 13개 생물권이 순환하는 작은 구세계 위의 매직 카펫 무한 비행 게임** — Firefox/Chrome에서 바로 실행되며 키보드 한 번, 마우스 클릭 한 번이면 하늘을 향합니다.

## 🌐 라이브 데모

> GitHub Actions가 `main` 브랜치 푸시마다 자동으로 빌드 + 테스트 + Pages 배포를 진행합니다.
> 배포가 활성화되면 `https://sigco3111.github.io/MagicCarpetWizard/` 에서 플레이할 수 있습니다.

## 🎮 조작법

| 키 | 동작 |
| --- | --- |
| `W` / `S` (또는 ↑ / ↓) | 상승 · 하강 |
| `A` / `D` (또는 ← / →) | 좌·우 조향 |
| 마우스 + 좌클릭 홀드 | 조준 + 마법 시전 |
| `1` / `2` / `3` | 파이어볼 · 라이트닝 · 윈드 블래스트 |
| `Q` | 마법 순환 |
| `R` | 여정 재시작 (또는 같은 코스/플레이어로 재시도) |
| `Space` | 4m 이상에서 바렐 롤 (적 투사체 회피) |
| `Shift` 홀드 | 스카이파이어 부스트 (25 파워에서 시작) |
| `Esc` / `P` | 일시정지 / 재개 |
| `M` | 음소거 / 해제 (Slumbr 환경음 + 녹음 효과음) |
| `Enter` | 시작 / 재시도 |

3.5m 아래로 낮게 비행하면 속도와 파워가 충전됩니다. 롤, 금빛 링 통과, 장애물 간근 회피, 적 처치 모두 콤보 체인을 쌓고 모래시계(슬로 모션 게이지)를 채웁니다. **하트는 단 3개** — 잃으면 비행이 끝납니다.

## ✨ 게임 시스템

### 9종 마법 (3 무기 + 6 강화)

| 키 | 이름 | 효과 |
| --- | --- | --- |
| `1` | 파이어볼 | 폭발 + 잔류 불길 |
| `2` | 라이트닝 | 즉시 적중, 감소 피해로 연쇄 |
| `3` | 윈드 블래스트 | 적 밀치기 · 적 탄환 제거 · 불길 부채질 |
| — | 프로스트 | 적 둔화; 얼린 적은 파이어에 산산조각 |
| — | 에코 | 추가 마법 볼트 |
| — | 자석 | 18초간 전리품 흡인 · 중첩 시 28 / 40 / 52m |
| — | 보호 (Ward) | 하트 회복 + 짧은 무적 |
| — | 하트 | 하트 회복 |
| — | 래피드 파이어 / 퓨리 / 포커스 / 오버드라이브 | 8~12초 시간제 부스트 |

### 진행

- **마법 레벨은 한 비행 내 영구** (재시작 시 초기화)
- **시간제 부스트**: 래피드 파이어 / 퓨리 / 포커스 (10–12초), 오버드라이브 (8초)
- **마법 크리스탈**은 최대 Lv 3 — 추가 중복은 오버드라이브로 변환
- **자석**은 18초 기본, 반복 획득 시 최대 32초까지 연장
- 점수 배율 최대 **8×**
- 거리/점수는 `localStorage` 에 저장 (최고 기록 자동 보존)

### HUD 표시

`$('#hud')` 가 표시하는 핵심 정보:

- **거리/점수/콤보 배율** — `distance`, `score`, `combo` 라벨
- **스카이파이어 게이지** — 낮게 비행하면 충전, `Shift`로 부스트
- **모래시계 게이지** — 적 처치/링 통과/롤 시 충전, 우클릭으로 슬로 모션
- **현재 마법 + Lv** — 마법 트레이 + 선택 표시
- **플라이트 모드** — 스카이파이어 상승 / 절벽 라이더 / 지면 효과 / 비단 나선 / 바람을 타다
- **보스 HP + 단계** — 보스 등장 시 화면 상단에 별도 표시
- **레이스 HUD** — 게이트 번호 · 거리 · 높이 · 고스트 비교

### 모래시계 (슬로 모션)

- 우클릭으로 시간 굽힘 — 적 탄환 회피와 정확한 조준에 사용
- 궁수 등장 시 자동으로 5초 슬로 모션 진입

## 🛠️ 개발

요구 사항: **Node.js 22** · WebGL 2 브라우저 · 데스크탑 마우스/키보드

```sh
npm ci           # 의존성 설치 (package-lock.json 기반)
npm run dev      # 127.0.0.1에서 개발 서버
npm test         # 88개 결정론적 단위 테스트 (Node test runner)
npm run build    # vite build → dist/
```

API 키는 필요 없습니다. Google Fonts는 시스템 폰트로 안전하게 대체됩니다. 모델 · 경관 · 입자 · 하늘 · 액션 이펙트 모두 코드 생성 (외부 에셋 의존 없음). 비행/전투는 90Hz 고정 스텝, 느린 프레임 후 보정 한도 적용. 일시정지/창 비활성 시 환경음 자동 페이드다운.

## 🚀 GitHub Pages 배포

이 저장소는 **`.github/workflows/pages.yml`** 으로 자동 배포됩니다.

1. `Settings → Pages → Build and deployment` 에서 **Source = GitHub Actions** 선택
2. `main` 브랜치 push (또는 PR) 시 자동으로:
   - `npm ci` → `npm test` → `npm run build` → `dist/` 업로드 → Pages 배포
3. `vite.config.js`의 `base: './'` 설정으로 저장소 서브경로에서도 자산이 정상 로드됨
4. 빌드 산출물 한도 1GB 이내 (현재 약 3.4MB — 한참 여유)

## 🎨 아트 디렉션

> Sable과 Chants of Sennaar의 분위기에서 영감을 받았으나, 모델과 텍스처는 모두 코드 생성 (외부 게임 에셋 사용 안 함).

- **셀 셰이딩** — 통합광 · 환경광 · 그림자를 3단계로 양자화 (차가운 그림자 + 따뜻한 하이라이트)
- **스크린-스페이스 잉크** — 거리 페이드 검은 실루엣과 내부 윤곽
- **절차 안료/모래결/카펫 직물 텍스처** — 정점 색상으로 베이크되어 모델에 부착, 빠른 비행 시 밉맵
- **HDR 글로우 + 1/4 해상도 블러** — 보케 없는 색상이 또렷이 살아남는 마법 발광 표현
- **8-bit 폴백** — 부동소수점 색상 타깃 미지원 브라우저를 위한 채도 게이팅 폴백
- **풀링된 입자** — 384 스파크 + 100 환경 모트 (양자화된 두 구름)

**번역 원칙**:
- 게임 분위기를 살리는 자연스러운 한국어 (직역 회피)
- 약어는 그대로 (`SHIFT`, `SPACE`, `Q`, `W`, `A`, `S`, `D`)
- 단위는 미터법 (`m`, `km/h`, `Lv`) 그대로 유지
- 보스 이름은 음역 + 직역 혼합 (예: `아즈라크 · 잿불 드래곤`)
- 마법명은 게임 커뮤니티에서 흔히 쓰이는 한국어 표기 사용 (파이어볼, 라이트닝, 윈드 블래스트)
